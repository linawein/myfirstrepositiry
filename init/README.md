## 🛠 Як працювати з репозиторієм у Visual Studio Code
1. Клонуйте репозиторій на свій комп'ютер: `git clone [посилання на репозиторій]`.
2. Відкрийте папку з проєктом у VS Code (`File` -> `Open Folder`).
3. Для перегляду Markdown-файлів використовуйте комбінацію `Ctrl + Shift + V`.
4. Для збереження змін використовуйте вкладку **Source Control** на лівій панелі або команди в терміналі:
   - `git add .`
   - `git commit -m "Опис змін"`
   - `git push`
